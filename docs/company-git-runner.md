The runner accepts only the seven fixed read-only commands used by `platform_source.NativeGit`. It checks an independently supplied SHA256 for the protected Git executable, copies that executable into a sealed memfd, and checks the source-root and executable identities around each command. Standard input is empty. Output, command counts, execution time and disposal time have finite shared limits.

Native execution requires the literal `trusted-company-station-exclusive-child-reaper-v1` caller contract. It verifies one actual Linux task and default SIGCHLD handling before launch and before termination. A non-consuming pidfd wait probe must still recognize the owned child before any numeric process-group signal; unknown ownership prevents signaling or waiting and retains the uncertain resources. Known child reaping precedes successful disposal.

The contract is a trusted caller obligation. Task checks do not prove that arbitrary trusted code cannot race a wait consumer. Executable sealing does not authenticate the ELF loader or shared libraries, and this runner does not claim containment of escaped descendants. A dedicated trusted company process and separately qualified station remain necessary.
